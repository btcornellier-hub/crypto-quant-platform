# Crypto Quant Platform

A research-first, low-frequency, spot-only systematic trading platform for BTC/ETH. Its first job is to find out, honestly, whether any strategy beats buy-and-hold after costs and taxes.

**Live trading is disabled.** No strategy has been validated. No results exist yet.
